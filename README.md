# Design System — Premium Motion & UI

This repository is a premium, motion-first Design System template focused on sophisticated visuals and high-quality animations. It includes tokens, motion guidelines, a starter UI package (React + Framer Motion), and Storybook setup.

Goals
- Premium aesthetic inspired by Apple, Nike, and large-brand motion systems.
- Motion-first tokens and patterns (durations, easings, springs).
- Ready for Storybook, Framer Motion components, and Lottie integration.

Getting started
1. Clone the repo
   - git clone git@github.com:gestorkiva-cmd/design-system-premium.git
2. Install dependencies (in packages/ui)
   - cd packages/ui && npm install
3. Run Storybook
   - npm run storybook

Structure
- /design — tokens and motion guidelines
- /packages/ui — UI component library (React + Framer Motion)
- /examples — demo site and hero animations (placeholder)
